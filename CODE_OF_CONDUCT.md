# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full and
without modification.

Read it here: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Plain-text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

The Covenant is not restated in this repository so that it cannot silently
drift from the canonical text. The linked document is authoritative.

## Reporting

Report unacceptable behaviour to the maintainer at
**griffinradcliffe@gmail.com**. All reports are reviewed and investigated
promptly and fairly, and the reporter's privacy and security is respected.

Maintainers who do not follow or enforce the Code of Conduct in good faith
may face temporary or permanent repercussions as determined by other members
of the project's leadership, per the Covenant's enforcement guidelines.

## Scope

The Covenant applies in all project spaces — issues, pull requests,
discussions, commit messages, code review — and when an individual is
officially representing the project in public spaces.

## A note specific to this project

OctetProof records disagreement between implementations as a first-class,
machine-checkable event. **A `DISAGREE` verdict is a finding about software,
never a judgement about a person.** Reporting that another project's reader
disagrees with yours is the protocol working as intended, and it is expected
to be discussed in those terms: which artifact, which field, which versions,
what the diff says. Framing a disagreement as incompetence or bad faith on
the part of another project's authors is a Code of Conduct matter.
